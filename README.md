Overview
A simple Java project demonstrating Object-Oriented Programming (OOP) and inheritance. It manages personal information for university students and teachers.

Features
Stores name, age, and gender.
Stores student details: degree program, CGPA, and semester.
Stores teacher details: designation, salary, and department.
Demonstrates inheritance, constructors, and code reusability.
Technologies
Java
Object-Oriented Programming (OOP)
Classes
uniPersonal — Parent class for personal information.
student — Stores student details.
teacher — Stores teacher details.
uni — Main class to run the program.
How to Run
Compile and run using:


javac uni.java
java uni
Purpose
Created for learning and practicing Java inheritance and basic OOP concepts.
